# Evaluation

Small synthetic-set evaluation (~40 sets, known ground truth) comparing:
1. exact-match baseline,
2. single-pass extraction + normalization,
3. the full agent (perturbation uncertainty + investigation).

Metrics: false-flag rate on genuine sets, detection rate on injected
discrepancies, degraded-capture handling. Reported honestly as a small
synthetic-set result; no real-world accuracy claims.
