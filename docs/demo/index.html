DocTrust

An open-weight reviewer agent that cross-examines a person's whole document set, re-reads anything it is unsure about, and shows the human reviewer the exact regions that agree or disagree. It never auto-rejects.

Demo mode

Demo mode — cached agent run on synthetic data. Live mode connects to Muse Spark Open via Baseten and SAM 3.1 on Modal (API keys required). Every document below is synthetic and marked SPECIMEN; nothing here is a real document or a real person.

Agent trace

    DocTrust is decision support for a human reviewer — it never auto-approves or auto-rejects. Uncertainty comes from disagreement between reads under perturbation, not from a model's self-reported confidence. Normalization and cross-examination are deterministic code, so every flag is traceable to a rule.
