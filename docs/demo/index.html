DocTrust

A reviewer agent that cross-examines a person's whole document set, re-reads anything it is unsure about, and shows the human reviewer the exact regions that agree or disagree. It runs on hosted Muse Spark or Muse Spark Open (open weights) — and never auto-rejects.

Demo mode

Demo mode — cached agent run on synthetic data. Live mode runs the real agent with Muse Spark (Meta Model API or Baseten) and SAM 3.1 via the Meta Model API (server-side keys required). Every document below is synthetic and marked SPECIMEN; nothing here is a real document or a real person.

    Agent's read on this evidence

    DocTrust is decision support for a human reviewer — it never auto-approves or auto-rejects. Uncertainty comes from disagreement between reads under perturbation, not from a model's self-reported confidence. Normalization and cross-examination are deterministic code, so every flag is traceable to a rule.
